# Security policy

Nova is pre-alpha and does not yet publish supported release lines. Please do not use it for
production or sensitive data.

Do not open public issues for suspected vulnerabilities. Use GitHub's **Report a vulnerability**
feature to submit a private security advisory to the maintainers. Include reproduction steps,
affected versions or commits, impact, and any suggested mitigation.

We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix
is available.
